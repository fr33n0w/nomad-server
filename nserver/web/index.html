Features

  • Many nodes, one app. Each node has its own identity, pages and files, and starts, stops or restarts on its own.
  • Web interface. Overview, stats, live log and settings, also on a headless server, with an optional password.
  • Edit pages in the browser. Write, upload, rename and move pages and files; saved pages are served at once.
  • Counters and traffic. Requests and bytes per page, per day and per hour, visit counters on the pages, crawler-like visitors marked.
  • Python pages on Windows too. Pages with a Python shebang run on every system, plus plugins for dynamic pages inside the server.
  • Footer and watermark. Optional visits line and "served by" line on every page, partials left alone.
  • Rate limit per visitor and the .allowed lists of NomadNet.
  • Light. Needs only rns; uses rnsd when it runs, otherwise its own instance.
